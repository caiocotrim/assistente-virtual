Curso: Bacharelado em Sistemas de Informação  
Assunto: Análise e Modelagem de Sistemas  
Sinônimos comuns: Análise de Sistemas, Modelagem de Sistemas, UML, Levantamento de Requisitos  
Descrição: A disciplina de Análise e Modelagem de Sistemas aborda técnicas e ferramentas essenciais para o levantamento e análise de requisitos de software. Os alunos aprendem a elaborar documentos de requisitos e a utilizar a UML para representar projetos orientados a objetos, incluindo diagramas de caso de uso, classes, sequência, atividades, componentes e transição de estados. A compreensão desses conceitos é fundamental para a arquitetura de software, preparando os estudantes para desafios práticos na área de desenvolvimento de sistemas.
