Curso: Bacharelado em Sistemas de Informação  
Assunto: Algoritmos e Programação  
Sinônimos comuns: Algoritmos, Programação, Lógica de Programação, Introdução à Programação  
Descrição: Este componente curricular aborda a resolução de problemas computacionais por meio de algoritmos, utilizando pseudocódigo e fluxogramas. Os alunos serão introduzidos a uma linguagem de programação, explorando conceitos como variáveis, tipos de dados, entrada e saída de dados, operadores, expressões, comandos de decisão e repetição, além de estruturas de dados homogêneas. O curso enfatiza boas práticas de programação e o uso de subprogramas, preparando os estudantes para desafios práticos na área de desenvolvimento de software.
