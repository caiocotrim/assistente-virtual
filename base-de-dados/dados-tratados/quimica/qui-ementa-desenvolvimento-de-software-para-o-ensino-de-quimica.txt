Curso: Licenciatura em Química  
Assunto: Desenvolvimento de Software para Ensino de Química  
Sinônimos comuns: Programação para Química, Algoritmos no Ensino, Software Didático em Química  
Descrição: Este documento aborda a criação de softwares voltados para o ensino de Química, enfatizando a lógica de programação e a construção de algoritmos. O curso visa capacitar os alunos a aplicar tecnologias de informação e comunicação em suas práticas pedagógicas, desenvolvendo ferramentas que facilitem o aprendizado dos conceitos químicos. A ementa inclui tanto aspectos teóricos quanto práticos, com foco em linguagens de programação aplicáveis ao contexto educacional.

Ementa:
Lógica de programação e programação estruturada. Linguagem de definição de algoritmos.
Estrutura de um algoritmo. Estudo de linguagem de programação de aplicação didática.
Estudo teórico e prático de linguagem de programação para aplicação dos conceitos de
construção de programas estruturados. Linguagem de programação. Construção de
algoritmos aplicados ao ensino da química.
Objetivos:
 Aplicar os conhecimentos relacionados às tecnologias de informação e comunicação,
aliado à formação pedagógica, no sentido de desenvolver softwares para serem utilizados
como ferramentas em sua prática profissional.
